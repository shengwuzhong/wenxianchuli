期刊/年份中各有 25 篇来自**文件名兜底**（`journal_from_filename` /
`year_from_filename`，低置信，`source=filename_fallback`）；只对能从
`序号_期刊_年份_作者` 解析、且期刊名含“研究/学会/紀要/Journal”等提示词的文档生效，
不会覆盖已有正常期刊或年份。文件名兜底不是独立准确率证据，仍不能替代人工 gold。

所以期刊非空率既包含缺失，也可能包含语义错位；在修 `issue.py` 前，
不应把该字段用于准确率验收。文件名兜底只改善“非空率”，不证明语义正确。
